# 📦 Power BI Supply Chain Performance Dashboard

## 📌 Project Overview

This project presents an interactive **Supply Chain Performance Dashboard** developed using **Microsoft Power BI**.

The dashboard transforms supply chain data into meaningful business insights, enabling users to monitor key performance indicators, analyze operational performance, identify trends, and support data-driven decision-making.

The project demonstrates practical skills in **Power BI, Power Query, DAX, data modeling, data visualization, and business intelligence**.

---

## 🎯 Objectives

The main objectives of this project are to:

- Monitor overall supply chain performance
- Track important operational KPIs
- Analyze product and supplier performance
- Identify trends and performance issues
- Transform raw data into meaningful business insights
- Provide an interactive dashboard for decision-making

---

## 🛠️ Technologies & Skills

- **Microsoft Power BI**
- **Power Query**
- **DAX (Data Analysis Expressions)**
- **Data Cleaning & Transformation**
- **Data Modeling**
- **KPI Development**
- **Data Visualization**
- **Business Intelligence**
- **Supply Chain Analytics**

---

## 📊 Dashboard Features

The dashboard provides visual analysis of key supply chain metrics, including:

- Revenue and sales performance
- Order and product performance
- Inventory-related metrics
- Supplier performance
- Shipping and delivery analysis
- Product category analysis
- Cost and operational performance
- Interactive filtering and slicing

---

## 🔄 Data Preparation

The dataset was prepared using **Power Query** before being used for analysis.

Data preparation included:

- Checking and correcting data types
- Handling missing or inconsistent values
- Removing unnecessary data
- Cleaning and transforming columns
- Preparing data for analytical reporting
- Creating relationships required for the Power BI data model

---

## 📐 DAX & KPI Analysis

DAX measures were created to calculate and analyze important business metrics.

Examples include:

- Total Revenue
- Total Orders
- Average Order Value
- Total Costs
- Profit / Performance Metrics
- Product and supplier-level KPIs

These measures allow the dashboard to dynamically respond to filters and user selections.
